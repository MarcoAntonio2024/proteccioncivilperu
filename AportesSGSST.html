Aportes Gratuitos para el Sistema de Gestión de Seguridad y Salud en el Trabajo

Ponemos a disposición aplicaciones y modelos de documentos que pueden servir como referencia para elaborar y/o actualizar el Sistema de Gestión de Seguridad y Salud en el Trabajo.

Información importante: Estos documentos y aplicaciones se proporcionan gratuitamente como material de orientación.

Aplicación web interactiva para evaluar el nivel de cumplimiento de su SGSST según RM 050-2013-TR. Funciona en celular y PC. Genera reporte PDF con brechas.
